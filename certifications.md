### 🤖 AI Security & Offensive Security
Certifications focused on practical AI security testing, adversarial techniques, and offensive security analysis.

| Certification | Issuing Org | What It Validates |
| :--- | :--- | :--- |
| **HTB COAE** (Certified Offensive AI Expert) | Hack The Box | **AI Security:** Validates hands on offensive AI skills including prompt injection, AI application testing, model abuse scenarios, and security assessment of AI enabled systems. |

<br>

### 🛡️ Blue Team & Defensive Operations
These certifications focus on practical SOC skills, incident response, threat hunting, security analysis, and defensive operations.

| Certification | Issuing Org | What It Validates |
| :--- | :--- | :--- |
| **HTB CDSA** (Certified Defensive Security Analyst) | Hack The Box | **SOC Analysis:** Practical defensive security covering log analysis, incident investigation, malware analysis, threat hunting, and SOC workflows. |
| **HTB CJCA** (Certified Junior Cybersecurity Associate) | Hack The Box | **Cybersecurity Operations:** Hands on junior cybersecurity skills spanning reconnaissance, exploitation fundamentals, Active Directory, security analysis, network fundamentals, and defensive awareness. |
| **BTL1** (Blue Team Level 1) | Security Blue Team | **Practical Defense:** Hands on SIEM, phishing analysis, digital forensics, threat intelligence, and incident response skills. |
| **CCDL1** (Certified CyberDefender Level 1) | CyberDefenders | **SOC Readiness:** Practical junior SOC analyst skills including alert triage, threat intelligence, phishing investigation, digital forensics, and incident response. |
| **CySA+** (Cybersecurity Analyst) | CompTIA | **Threat Detection:** Security operations, vulnerability management, incident response, threat intelligence, and behavioral analytics. |
| **SAL1** (Security Analyst Level 1) | TryHackMe | **Junior Analyst Skills:** Cyber defense frameworks, alert triage, investigations, and case reporting through practical scenarios. |

<br>

### ☁️ Cloud Security & Zero Trust
Specialized credentials focused on cloud security architecture, governance, and modern identity centered security models.

| Certification | Issuing Org | What It Validates |
| :--- | :--- | :--- |
| **CCSK v5** (Certificate of Cloud Security Knowledge) | Cloud Security Alliance | **Cloud Security:** Architecture, governance, compliance, data security, IAM, and cloud security operations. |
| **CCZT** (Certificate of Competence in Zero Trust) | Cloud Security Alliance | **Zero Trust:** Identity centered security, least privilege, segmentation, policy enforcement, and Zero Trust architecture principles. |

### 🧱 Core Security Foundations
Credentials establishing a strong baseline across cybersecurity principles, risk, access controls, and security operations.

| Certification | Issuing Org | What It Validates |
| :--- | :--- | :--- |
| **Security+** | CompTIA | **Core Security:** Threats, architecture, security operations, access control, risk, and incident response fundamentals. |
| **CC** (Certified in Cybersecurity) | ISC2 | **Security Principles:** Foundational security concepts, business continuity, disaster recovery, access controls, network security, and security operations. |
| **Google Cybersecurity Professional Certificate** | Google / Coursera | **Technical Foundations:** Linux, SQL, Python, SIEM concepts, incident response, network security, and entry level analyst workflows. |
| **Google & CompTIA Dual Credential** | Google / CompTIA | **Dual Validation:** Recognition for completing the Google Cybersecurity Professional Certificate and earning CompTIA Security+. |
